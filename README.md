# Prescriptive Analytics

Notas de clase del curso *Prescriptive Analytics* (antes Metaheurísticas), Departamento de Ingeniería Industrial, Universidad de los Andes.

El libro está publicado en <https://pozost.github.io/Prescriptive-Analytics/>.

## Compilar el libro

```bash
pip install -r requirements.txt
jupyter-book build .
```

Los cuadernos se guardan con sus salidas y el libro no los vuelve a ejecutar. Para ejecutarlos se necesitan las bibliotecas de `requirements-curso.txt`.
